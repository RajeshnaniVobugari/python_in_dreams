# Day 03 – Expenses Tracket

## Overview

This project demonstrates Python concepts including:

- **Dictionaries** – for managing the expenses of the user
- **Loops** - for iterating the expenses amount
- **Conditional Statements** – to determine the expenses  

The goal is to build a **Expenses tracker** that can:

1. Add the budget 
2. Add the expenses according to the category
3. Calculate total expenses


## Example Output and input

Enter the budget to spend the expenses : 1000
Expenses_list : [{'name': 'Coffee', 'category': 'Cold Coffee', 'amount': 300}]
